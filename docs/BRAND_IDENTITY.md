# Brand Identity

The public repository follows the existing Agent Forge identity. It does not introduce a portfolio-only visual system.

## Core idea

**Agent Forge — Burning Within**

The identity combines a dark forge environment, controlled fire, precise technical typography, and the idea of Ṛta: ordered movement rather than decorative chaos. The website uses cinematic motion; the product workspace uses denser operational surfaces.

## Canonical palette

| Role | Value | Use |
|---|---|---|
| Brand fire | `#ff4500` | Primary brand signal, selected state, and logo energy |
| Hot flame | `#ff6600` | Highlights and active fire motion |
| Ember | `#cc1100` | Deeper gradient and secondary brand energy |
| Void | `#070709` / `#0a0502` | Primary dark environment |
| Elevated surfaces | `#0d0d12` through `#242432` | Product workspace depth |
| Primary text | `#e2dede` / `#f0e8e0` | Headings and critical information |
| Secondary text | `#9a9ab0` | Explanatory copy and metadata |

Brand fire is not a universal status color. Success, warning, information, and failure retain their own semantic colors so operational meaning stays legible.

## Typography

The identity has two related expressions:

- **Public website:** Bebas Neue for cinematic display, Barlow for editorial body copy, and DM Mono for technical labels.
- **Product workspace and brand documentation:** Syne for product display and Space Mono for operational metadata.

The split is intentional: the website creates entry and emotion; the application optimizes dense system comprehension.

## Mark

The official angular forge mark is stored at [`assets/brand/agent_forge_logo_v3.svg`](../assets/brand/agent_forge_logo_v3.svg). Preserve its proportions, clear space, and fire palette. Do not substitute unrelated geometric marks or recolor it as a status indicator.

## Motion and texture

- Fire, embers, harmonic lines, seals, and scan motion communicate energy and ordered transformation.
- Motion should reveal hierarchy or system state, not decorate every surface.
- Reduced-motion preferences must preserve access to all content.
- Product screenshots must come from the existing public website or labeled public tour.

## Repository application

GitHub is the documentation surface. The README uses the official mark, authentic product captures, the fire palette in badges, and Mermaid diagrams for engineering relationships. Repository links point to the existing website instead of presenting a second branded product.
