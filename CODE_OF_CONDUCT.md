# Code of Conduct

## Our standard

We commit to a respectful, professional, and harassment-free project environment. Constructive technical disagreement is welcome; personal attacks, discriminatory language, harassment, and disclosure of private information are not.

## Public-boundary responsibility

Never post credentials, private repository content, personal data, customer information, internal prompts, or production incident details in issues, discussions, pull requests, or screenshots.

## Enforcement

Project maintainers may edit, remove, or reject contributions and participation that violate these expectations. Serious or repeated violations may result in a temporary or permanent ban from project spaces.
